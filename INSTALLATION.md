# Installation

## Supported browsers

Rhythia Reimagined 1.1.0 officially supports:

- Google Chrome 116 or later
- The current version of Opera

Other browsers are not officially supported, even if the extension appears to
install or run.

## Install from the official store listing

Install [Rhythia Reimagined from the official Chrome Web Store listing](https://chromewebstore.google.com/detail/rhythia-reimagined/ekjfnmfocjohkiieakohbnagjcdbfolb)
only from that official listing. Follow the browser's extension-installation
prompt and review the permissions shown before confirming installation.

After installation, open a Rhythia page and use the extension normally. Keeping
the browser current helps ensure compatibility and security.

## Distribution & GitHub Notice

This GitHub repository is maintained strictly for source inspection, documentation,
and issue tracking. **Installable zip files or pre-packaged binaries are not
distributed via GitHub Releases.** Always install and update via the official
Chrome Web Store link above.

## Updates and removal

Store-installed extensions are updated through the browser's normal extension
update process. Removing the extension does not necessarily remove its local
browser data or any backup files in a user-selected folder. Review
[Data and Backups](DATA-AND-BACKUPS.md) before removing it if you want to keep
or delete that data.

## Troubleshooting

Confirm that the extension and browser are current, then see
[Support](SUPPORT.md) if the issue continues. Do not post session values,
cookies, exports, or backup files in an issue.
