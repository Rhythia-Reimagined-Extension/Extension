# Security Policy

## Reporting a vulnerability

Please do not include authentication sessions, cookies, private messages,
profile exports, local backups, or other sensitive data in a public issue.

For a suspected security problem, email `shurieldev@gmail.com` before opening
a public issue. Include the affected extension version, browser and version, a
short description, impact, and the minimum steps needed to reproduce the
problem. Do not rely on a GitHub profile for confidential reports. Redact any
account, session, export, backup, or personal information from the report.

Please allow time for the report to be assessed and a fix to be prepared before
public disclosure. The maintainer will coordinate a disclosure timeline with the
reporter when possible.

## Supported release

Security reports for the current production release, 1.1.0, are accepted.
Officially supported browsers are Google Chrome 116 or later and the current
version of Opera.

## Local data

Local browser data and backup files are not a secure vault. Anyone who can
access the browser profile or selected backup folder may be able to read them.
Protect the device, browser profile, and backup location appropriately.

The extension depends on Rhythia pages and official Rhythia services. Capo Games
may change those services or the terms that apply to accounts, which can affect
the extension. This project is not affiliated with or endorsed by Capo Games.
Users are responsible for reviewing the terms that apply to their Rhythia
account before using the extension.
