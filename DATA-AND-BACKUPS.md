# Data and Backups — legacy documentation link

Rhythia Reimagined 1.2.0 removed the former backup, export, and import controls. Settings and supported local profile history are migrated from 1.1.0; obsolete backup configuration is removed. Previously exported files on your device are not deleted by the extension.

See [Data and Sync](DATA-AND-SYNC.md) for current storage, retention, optional community connections, and clearing data, and [Privacy](PRIVACY.md) for data handling.
