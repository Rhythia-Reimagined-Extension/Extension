# Data and Backups — legacy documentation link

Version 1.2.0 (then called Rhythia Reimagined) removed the former backup, export, and import controls. Settings and supported local profile history are migrated from 1.1.0; obsolete backup configuration is removed. Previously exported files on your device are not deleted by the extension. Since 1.4.0, the popup's Data tab can save the settings and own themes of both looks to a file and load them back, without history; files from 1.1.0 cannot be loaded.

See [Data and Sync](DATA-AND-SYNC.md) for browser storage, optional connections and clearing data, and [Privacy](PRIVACY.md) for extension data handling. Recovery copies of the independent history service are separate; see its [notice](HISTORY-PRIVACY.md#retention).
