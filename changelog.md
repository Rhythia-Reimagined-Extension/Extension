## 1.0.1 - Release Fixes - 2026-08-09

## Added

- Clearer category icons and section badges to changelog entries.
- Published the official [Chrome Web Store listing](https://chromewebstore.google.com/detail/rhythia-reimagined/ekjfnmfocjohkiieakohbnagjcdbfolb) for Rhythia Reimagined.

## Fixed

- Fixed the changelog footer so its colors follow every theme and remain part of the page.
- Restored Watch Replay and Download Replay actions on redesigned score cards.
- Score cards no longer show actions that do not apply to the current score.
- Profile history and Title Progression now update reliably after profile refreshes.
- Player Compare now keeps its panel open after `Clear` removes all selected players. Use `×` to close it.

## Changed

- The home promo video now fills the available space across all themes.
- Related statistics panels now share a compact, collapsible layout and start closed.
- Score-card arrows, headings, and contrast are easier to read.
- The extension requests less browser access while profile and friend features continue to work normally.

## 1.0.0 - 2026-08-06

## Featured

- Official production release of Rhythia Reimagined.

## Added

- Official browser support for Google Chrome 116+ and current Opera.
- Enhanced Rhythia profile and score views, performance statistics, filters, progression and rank tracking, and profile comparison tools.
- Local history and storage management, with optional manual, automatic, and recovery backups in a user-selected folder.

- See [Installation](INSTALLATION.md) and [Data and Backups](DATA-AND-BACKUPS.md) for usage information.
