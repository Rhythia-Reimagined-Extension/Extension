# Security — Rhythia Reimagined 1.2.1

If you find a security issue in the extension or its community service, please report it privately to [contact@shuriel.com](mailto:contact@shuriel.com).

Include the affected version and browser, what happened, and steps to reproduce it. Use **[SECURITY] Rhythia Reimagined** as the subject. Please give the maintainer time to investigate and fix the issue before publishing details. Do not send passwords, session tokens, or private login cookies.

Security fixes target the latest release. This repository contains the 1.2.1 source; store availability can differ while an update is under review.

The extension does not ask for passwords. Your Rhythia session is used only for official game features and is never sent to the community service. Connections use HTTPS, and executable extension code is bundled. See [extension Privacy](PRIVACY.md) for browser controls and the [service notice](HISTORY-PRIVACY.md) for independently collected history. Other VPS projects are outside this document.
